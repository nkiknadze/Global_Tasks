# Real-Time Chat Application with Rooms 🚀

ეს არის მარტივი, მაღალეფექტური ჩატის აპლიკაცია, რომელიც აგებულია **Node.js**, **Express** და **Socket.io**-ს გამოყენებით. პროექტი მხარს უჭერს რეალურ დროში მესიჯების გაცვლას და მომხმარებლების განაწილებას სხვადასხვა ოთახებში (Rooms).

## ✨ ფუნქციები

- **Real-Time Communication:** მესიჯების მომენტალური გაცვლა WebSockets-ის (Socket.io) მეშვეობით.
- **Chat Rooms:** მომხმარებლებს შეუძლიათ შეუერთდნენ კონკრეტულ ოთახებს (მაგ: Gita, General).
- **Broadcast Notifications:** სისტემა ატყობინებს ოთახის წევრებს ახალი მომხმარებლის შემოსვლის შესახებ.
- **Simple UI:** სუფთა და გასაგები ინტერფეისი.

## 🛠 ტექნოლოგიები

- **Backend:** Node.js, Express.js
- **Real-Time:** Socket.io
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
